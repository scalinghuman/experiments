# Ring Local

Personal, noncommercial companion experiment for an owned Oura Ring 4, using direct Bluetooth to a nearby iPhone and local data storage. No exported-data collection or required cloud relay.

## Status

Project setup only. Native app, pairing and physical-device validation are pending. Source is not published here.
