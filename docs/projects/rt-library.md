# RT Library

A personal community contribution: an iPhone and iPad catalog for the shared
library at Riviera Towers West New York. Built for co-op shareholders to browse
books by title, author and genre.

## Current release

Version 1.0 includes 653 OCR-derived book candidates across 50 genres. Shelf
photos and OCR generate the catalog, so some entries need review or correction.
Book requests, shared availability and donation flows are planned for a later
release. Private implementation and building shelf photos are not published here.
