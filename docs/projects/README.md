## Tracking convention

One GitHub Project per app can link back to `scalinghuman/experiments` and track issues from the relevant implementation repository. Suggested status flow: Todo → In progress → Done. Use app-specific labels in this shared repo. Project boards are GitHub metadata; the documentation files here are their stable reference material. Boards have not yet been configured.

[Repository overview](../../README.md)

Keep old document paths and published downloads reachable during future changes.
The website's [link policy](https://github.com/scalinghuman/website/blob/main/docs/link-policy.md)
records the migration requirements. This directory is an index, not a source
relocation or a change to any project's license.
